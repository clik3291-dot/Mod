# No Pause Inject

Клиентский Fabric-мод для Minecraft **1.21.8**. Блокирует открытие экрана паузы
(меню по Escape), в том числе если это меню вызывает не сам игрок, а сам
лаунчер (актуально для PojavLauncher/MojoLauncher на Android — известный баг,
когда при сворачивании приложения лаунчер сам "нажимает" Escape).

Работает как переключатель: клавиша **N** включает/выключает блокировку
(по умолчанию включена). Сообщение об состоянии показывается в чате.

## ⚠️ Важно перед использованием

Я (Claude) не могу собрать готовый `.jar` в своей песочнице — нет доступа в
интернет, а сборка Fabric-мода требует скачивания Minecraft/Gradle/маппингов.
Собери сам одним из способов ниже — оба бесплатны и не требуют компьютера с
JDK, если не хочешь ставить его локально.

## Способ 1 — собрать через GitHub Actions (проще всего, без ПК)

1. Создай **новый пустой репозиторий** на github.com (можно приватный).
2. Залей туда все файлы из этого проекта (через веб-интерфейс GitHub —
   кнопка "Add file → Upload files" — можно перетащить всю папку).
3. Перейди во вкладку **Actions** репозитория — сборка запустится
   автоматически (файл `.github/workflows/build.yml` уже включён).
4. Когда сборка закончится (зелёная галочка), открой этот прогон и
   скачай архив **nopauseinject-jar** внизу страницы — внутри будет
   готовый `.jar`.

## Способ 2 — собрать на ПК

Нужны: JDK 21, интернет.

```
gradle build
```

(или `./gradlew build`, если добавишь gradle wrapper — `gradle wrapper`
первой командой). Готовый `.jar` появится в `build/libs/`.

## Установка

1. Убедись, что стоит **Fabric Loader 1.21.8** и **Fabric API** той же версии.
2. Скопируй `nopauseinject-<версия>.jar` в папку `mods` (в MojoLauncher это
   обычно `.minecraft/mods` внутри его файлового менеджера/хранилища профиля).
3. Запусти игру, зайди на сервер — блокировка активна по умолчанию.
   Нажми **N**, если нужно временно вернуть обычное поведение (например,
   чтобы открыть меню и выйти/зайти в настройки).

## Как это работает

Мод перехватывает вызов `MinecraftClient.setScreen(...)` и отменяет его,
если туда пытаются подставить `GameMenuScreen` (экран паузы). Причина вызова
неважна — хоть реальный Escape, хоть системная потеря фокуса, хоть
синтетическое нажатие от лаунчера.

## На заметку

- Это чисто клиентская модификация, она не даёт игрового преимущества —
  просто не даёт всплывать меню. Но на некоторых серверах могут быть свои
  правила насчёт AFK/автоматизации (например, если это используется для
  долгого автофарма без присутствия игрока) — уточни правила своего сервера,
  чтобы не словить бан за обход анти-AFK систем.
